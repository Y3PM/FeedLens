已修复订阅源/文章/OPML URL 协议边界、自定义阅读器 URL、预览 fetch 输入及 HTML 降级路径；收紧扩展消息接收者。确认的是代码缺陷及模拟复现结果，没有证据证明本扩展已遭利用或与此次 DeepSeek 异常消费相关。

检查了 `manifest.json`、`src/`、`vendor/`、语言资源、README 和现有文档。未找到独立部署说明、服务器、付费 AI 接口、上传/导出服务或秘密录入界面。本项目为无需构建的 unpacked 扩展；服务端 SSRF、付费预算与服务端身份校验不适用于当前实现。

## 凭据与产物检查

- 沿用 11 月 18 日对所有本地可达分支/远程引用/标签的历史检查：72 个独立 blob；常见服务商 Key、Token、私钥及秘密赋值模式无命中。机器结果位于 `/private/tmp/feedlens-secret-scan-2026-11-18.json`。没有重复扫描历史。
- 收尾补查工作树（含未跟踪/被忽略文件）的 24 个文本文件及 `.git/config`，同类模式无命中；本仓库内无 ZIP/CRX/归档或 source map。二进制宣传图片未 OCR；模式扫描不能排除任意格式秘密。
- 源码人工追踪未发现 AI Key、Pro Token、Authorization 请求或解密后回填第三方 DOM 的路径。现存 localStorage 仅记录 OPML 点击状态和自定义阅读器 URL 模板；不将其视为秘密保管位置。
- 剪贴板降级临时 textarea 仅承载待复制订阅链接；当前 reader 是扩展自身页面。无已保存 API 秘密回填问题。订阅链接/自定义 URL 仍可能本身含私人查询参数，用户复制、分享及交给外部阅读器时需自行判断；本次未迁移存储键。
- GitHub 发布包只读清单查询在受限网络中连接失败；提权重试被自动审批系统阻止，原因是额度限制导致审批无法完成，并非安全否决。未绕过审批，未下载检查远端发布包或浏览器商店实际安装包。

## 权限、HTML、依赖与剩余边界

- `tabs`、`webRequest` 和 HTTP(S)/file host 权限服务于自动发现、检测和预览；本次未扩权。file 仍需用户在浏览器中单独启用。manifest 没有 web_accessible_resources、外部消息或脚本远程加载入口；reader 从本地文件加载脚本，使用 MV3 默认 CSP。
- 正文沿用明确标签/属性白名单和 DOMPurify，移除脚本、事件、样式、iframe/object/embed；链接/图片先经过本次 URL 校验。元数据文本维持 HTML 转义；原文跳转保持 noopener/noreferrer。
- vendor 头部版本为 DOMPurify 3.4.8。11 月 18 日查看了上游公告列表与 3.4.18 发布说明；其中所阅公告涉及 SAFE_FOR_TEMPLATES、IN_PLACE、hooks/DOM 输出等配置，本项目使用普通字符串 sanitize，未启用这些配置。没有针对本项目可达配置确认依赖漏洞，故未盲目升级。未逐一穷尽全部公告或核对 vendor 与上游构建的字节一致性，不能宣称依赖完全无漏洞。
- 未增加服务端代理；远程订阅源和图片仍由客户端访问。HTTP 源仍保留以兼容现有流程。远程图片、跟踪 URL、超大/深层 XML 的隐私及资源占用没有在本次收尾扩展处理；没有把它们写成已修复或服务端 SSRF。
